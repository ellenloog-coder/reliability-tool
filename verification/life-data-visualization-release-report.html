Implementation Summary

Probability PlotUses ln(t) on X and ln[-ln(1-F)] on Y with required Weibull probability ticks from 1% to 99%.
Plotting PositionsFailure plotting positions are generated by Kaplan-Meier survival estimates with grouped right-censored data handling.
Censored DisplayRight-censored observations are rendered as bottom rug markers, not probability points.
Fitted LineThe fitted line is rebuilt from the active beta and eta over the active data time range with a 10% margin.
Reliability CurveR(t) is the default. F(t) toggle updates the curve without refitting and hides the target reliability line in F(t) mode.
TablesAdded B1/B5/B10/B50 plus custom percentile, and reliability at selected times plus custom time.
InsightAdded failure-rate trend interpretation using beta thresholds: below 0.9 decreasing, 0.9 to 1.1 constant, above 1.1 increasing. No root-cause claim is made.
Report SyncExported report includes upgraded SVG plots, limitations, percentiles, selected times, target gap, and default curve view.
